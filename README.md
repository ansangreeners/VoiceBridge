# VoiceBridge

갤럭시 음성/타이핑을 PC 커서에 블루투스로 직결 입력하는 안드로이드 앱.
**PC에 드라이버·소프트웨어 설치 0** — 폰을 BT 키보드로 위장(HID).

## UI 흐름 (카톡식)
1. 하단 메시지입력박스 탭 → 갤럭시 키보드(순정) 팝업
2. 마이크 또는 키보드로 입력 → 상단 텍스트박스에 실시간 표시
3. 키보드 내리고 상단 빈 영역 탭(또는 [전송] 버튼) → PC로 전부 + 엔터 전송

## 빌드 방법 (GitHub Actions, PC 불필요)
1. 이 저장소의 **Actions** 탭으로 이동
2. **Build APK** 워크플로우 → **Run workflow** 클릭
3. 빌드 완료 후 (약 3~5분) → 하단 **Artifacts**에서 `VoiceBridge-APK` 다운로드
4. 압축 풀고 `app-debug.apk`를 폰에 설치

## 사용법
1. 앱 실행 → 블루투스 권한 허용
2. PC 블루투스 설정에서 "VoiceBridge" 페어링 (키보드로 잡힘)
3. 메시지 입력 → 상단 빈곳 탭 → PC 커서 위치에 입력됨
4. PC 한글 입력은 PC IME를 한글 모드로 두고 전송

## 권한
- 블루투스 권한만. 인터넷·접근성·녹음 권한 없음.
